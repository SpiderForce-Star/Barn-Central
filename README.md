## What’s on the site

- Home, work gallery, services, about, and a quote tool that emails `sales@thebarncentral.com`
- **Official circular logo** (Facebook profile mark)
- **Job photos from Barn Central’s Facebook** — including the 50×60×16 dual-porch shop in Bethpage (posted Sept 1, 2026)

No stock barns. No invented testimonials or awards.
