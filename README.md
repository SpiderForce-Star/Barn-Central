**Email** [sales@thebarncentral.com](mailto:sales@thebarncentral.com)  
**Facebook** [Barn Central](https://www.facebook.com/profile.php?id=61587244332260)

## What’s on the site

- Home, work gallery, services, about, and a quote tool that emails `sales@thebarncentral.com`
- **Official circular logo** (`public/logo.png`)
- **Job photos from Barn Central’s Facebook** in `public/buildings/` — including the 50×60×16 dual-porch shop in Bethpage (posted Sept 1, 2026)

No stock barns. No invented testimonials or awards.
